# G3 #73 · 힙합 골목 데스크톱 활동 검수

실행 G3-73-desktop-20261108 · 데스크톱 Chrome 156.0.8078.81 · 소프트웨어 WebGL · 맵 05d-2.v1 (PR #86, SHA-256 c2a1cfa737ee846bccc9deb65c45d36860de4ef402e425197410ddf5a5529afc).

로컬 시험 환경에서 시험 회원으로 로그인한 뒤 로비의 **힙합 → 데스크톱 활동 검수**로 진입한다. WASD로 바닥의 원 안에 들어가 활동 버튼을 누르고, ‘활동 끝내기’로 도보 시점에 복귀한다. 기존 시험 루프를 재생한다. 힙합의 공개 전환과 서비스 음원은 별도 작업이다.

- 관찰 회원 1명과 자동 접속 59명이 같은 방에 들어가 두 확장 단계가 열린 상태를 확인했다. 관찰 회원이 직접 걸어 [메인 홀](street.jpg) (0,0,1), 동쪽 [배틀존](battle.jpg) (12,0,-8)에서 각각 춤을 시작·종료했다. 별도 접속에서도 해당 회원의 위치와 춤 상태를 확인했다.
- 메인 홀로 돌아와 서쪽 골목 경사로를 올라 [루프탑 포토존](roof.jpg) (-13,3.5,-16)에서 포즈와 PNG 다운로드를 확인했다. 저장은 사용자 기기 내에서 이뤄진다.
- 방 단위 검증은 시험 시계로 개방과 축소를 진행했다. 축소 중 루프탑 신규 진입을 거부하고 기존 이용자가 퇴장한 뒤에도 보호 예약을 유지했다. 예약을 해제하자 상층부터 닫혔다. 재현 명령은 저장소 루트에서 `node --test validation/zones/hiphop-room.test.mjs`다.
- 혼잡 시 기능 확인에 접속 60개를 사용했다. 장시간 성능 시험은 범위에 포함하지 않았다. 모바일과 서비스 음원 권리 증빙은 보류한다.
