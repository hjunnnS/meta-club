# G3 #74 · 소셜 라운지 테이블 모임

데스크톱 실행 G3-74-desktop-20261108. Chrome 156.0.8078.81, 소프트웨어 WebGL, 시험 회원과 기존 시험 루프를 사용했다. 기준 맵은 PR #87에서 확정한 05d-3.v1이며 GLB SHA-256은 822525b9c77dbb693f9b41227b0ecd257b41b7d18ab2f1e7d44574bf524652f3이다.

로컬 시험 로비에서 **소셜 라운지 → 데스크톱 활동 검수**를 선택한다. WASD로 테이블 가까이 이동해 앉으면 같은 테이블에 앉은 사람끼리 글을 주고받는다. 일어서면 도보 시점으로 돌아온다.

- 배치는 확정 맵의 좌석 후보점 33개 중 각 구역에서 가장 가까운 두 점을 사용한다. 메인 라운지·정원·카페·부스·VIP 테라스·루프탑에 2인 테이블이 하나씩 있다. 정원과 부스는 1단계, 두 테라스는 2단계다.
- 데스크톱 브라우저 1개와 자동 접속 59개가 같은 채널에 입장해 두 단계가 열렸다. 그중 두 회원이 정원과 루프탑까지 걸어가 서로 다른 의자에 착석하고 메시지를 주고받은 뒤 일어섰다. 제3의 접속에는 대화가 전달되지 않았다. [정원 화면](garden.jpg) · [루프탑 화면](roof.jpg)
- 서버 시험에서는 한 의자에 두 명의 착석이 거부되고, 다른 테이블의 착석자에게도 대화가 전달되지 않았다. 축소 중 루프탑 진입은 차단됐으며 착석자는 계속 머물렀다. 이용자 퇴장 뒤에도 기존 보호 예약이 유지됐고, 예약 해제 후 상층이 닫혔다. 재현 명령은 저장소 루트에서 `node --test validation/zones/social-room.test.mjs`다.
- 60접속 결과는 혼잡 상태의 기능 검수다. 모바일 검수와 서비스 음원 증빙은 후속 작업이다.
