# G3 #75 · 레트로 디스코 데스크톱 검수

실행 G3-75-desktop-20261108. 기준은 #22와 PR #88에서 확정한 05d-4.v1이며 GLB SHA-256은 c482682b479d7eb4ba018fddb22389ccb5a4798461481c5b82a49ad32700e73f다. Chrome 156.0.8078.81, 소프트웨어 WebGL, 기존 시험 음원을 사용했다.

시험 회원으로 로그인하고 로비에서 **레트로 디스코 → 데스크톱 활동 검수**를 선택한다. WASD로 홀 바닥의 원에 접근해 춤을 시작하고 ‘활동 끝내기’로 도보 시점에 복귀한다. 구역은 중앙 홀·DJ 스테이지, 1단계 보조 홀 A, 2단계 보조 홀 B·라운지·바 순서다.

- 독립 자동 접속 59개를 세 홀에 나눠 춤을 시작했다. 데스크톱 관찰 회원이 입구에서 [중앙 홀](main.jpg), [왼쪽 A홀](A.jpg), [오른쪽 B홀](B.jpg)로 걸어가 각각 합류했다. 매 지점에서 서버가 춤 상태 60명을 보고했고 관찰 회원은 종료 후 계속 이동할 수 있었다.
- 중앙에서 높이 5.2m의 미러볼과 바닥 반사광, 춤을 한 화면에서 확인했다. 양 끝 홀에서는 출입구 너머로 같은 미러볼이 보인다. 세 지점에서 300ms 간격으로 두 번 읽은 미러볼의 회전값이 변했고 바닥 반사광의 회전값과 일치했다.
- 서버 시험 시계를 사용해 닫힌 홀 입장 및 원거리 춤 시작 거부, 순차 개방, 축소 중 신규 입장 거부와 기존 이용자의 춤 유지, 자발적 퇴장 뒤 보호 예약 유지, 예약 해제 후 역순 폐쇄를 확인했다. 재현 명령은 저장소 루트에서 `node --test validation/zones/retro-room.test.mjs`다.
- 이번 검수는 혼잡 상태의 데스크톱 기능 확인이다. 모바일 검수와 서비스 음원 권리 증빙은 후속 작업이다.
