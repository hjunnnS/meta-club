# #167 퍼레이드 시작 불가처럼 보이는 개인 체험판 수정

2026-11-13. 기존 G2 Milestone #3 / Epic #8 / Implementation #167. 신규 Issue/판매 정책/정기 공연 변경 없음.

## 재현과 원인
공개 체험판 v64에서 입장 후 VIP 이벤트를 열었다. 다음 레이저까지28초인 시점에 정식 시작 버튼이 비활성화되고 ‘완주하려면 다음 공연까지50초 이상 필요’가 표시됐다. 콘솔 오류와 최근 Sites 실패 로그는 없었다. 이후 다음 공연54초 전에는 버튼이 활성화됐지만50초 경계를 지나면 다시 비활성화됐다.

45초 한 바퀴+5초 여유 규칙 때문에 초기30초 레이저와90초 홀로그램 사이에 충분한 틈이 없고 첫 실행 기회는 대략 입장105~110초 뒤다. 실행 코드를 고장으로 단정하지 않고, 체험판에서 즉시 확인할 경로가 없던 문제로 처리했다.

## 수정
- 개인 체험판 VIP 이벤트에 ‘퍼레이드 바로 보기 · 시험’을 추가했다. 대기·재사용 제한 없이 기존45초 여성 NPC/양손 병/한 바퀴 렌더러를 재사용한다.
- 정기 공연은 그대로 재생한다. 수동 시험은 동시에 보일 수 있으며 화면에서 시험임을 명시한다. 정상 정기 공연 보호/순서 정책을 변경하지 않는다.
- 시험은 정식 사용자/클럽 재사용 시간을 소비하지 않는다. 두 퍼레이드를 겹쳐 만들지 않으며 정식 퍼레이드 중에는 시험을 시작할 수 없다. 시험 중 정식 실행도 차단한다. 종료 버튼과45초 만료로 정리한다.
- 정식 시작이 잠겨 있으면 다음 실행 가능 구간까지의 시간을 표시한다. 향후 공연 시각을 읽어서 계산하며 공연을 예약·이동·지연시키지 않는다.
- vip-preview는 개인 PersonalRoom에서만 처리한다. Colyseus 정식 command/handler에 우회 기능을 추가하지 않았다. 실제 서비스의 기존2분/종료후1분/정기 공연 우선·예약 없음 유지.
